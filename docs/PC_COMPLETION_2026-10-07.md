# WavCloud Windows PC 앱 구성 결과

Windows x64 개인용 앱 `0.1.0`을 `desktop-app/`에 추가했다.
운영 웹 UI를 전용 Electron 창으로 사용하며 별도의 화면 복사본을 관리하지 않는다.
웹 UI 수정은 웹 배포로, PC 창·런타임 수정은 새 Windows 설치 파일로 적용한다.

## 구성

- Electron `44.6.0`, electron-builder `26.15.3`. 버전·의존성 잠금 파일 포함.
- NSIS 현재 사용자 설치형과 관리자 권한 없이 실행하는 무설치형.
- WavCloud 아이콘·시작 메뉴·바탕화면 바로가기, 한국어 앱 메뉴.
- 트레이 이동·복원·완전 종료. 트레이를 사용할 수 없으면 창 닫기를 정상 종료로 처리.
- 창 크기·최대화·닫기 설정 복원. 모니터가 사라지면 화면 안으로 재배치.
- 로그인·재생목록·음원 캐시를 PC 앱의 지속 세션에 보관. 설치 제거 시 자동 삭제하지 않음.
- 재생 중 자동 절전 방지, 일시정지·화면 프로세스 종료·앱 종료 시 해제.
- 연결 실패·화면 프로세스 종료 시 다시 열기 화면. 사용자 데이터를 삭제하지 않고 재시도.
- 전용 프로필에서 웹과 같은 검색·재생·대기열·업로드·오프라인 저장 사용.
- 계정·인증 정책과 재생목록 서버 동기화는 변경하지 않음.

서비스 화면의 Node.js·IPC·webview를 비활성화하고 sandbox·contextIsolation·웹 보안과 인증서 검증을 유지한다.
서비스 외 탐색·팝업을 차단하고 권한을 서비스의 지속 저장·전체 화면으로 한정한다.
창 설정 파일에는 창 설정만 기록하며 계정이나 토큰을 기록하지 않는다.

## 검사 결과

| 항목 | 결과 |
| --- | --- |
| PC 앱 Node 검사 | 9개 통과. URL·권한·모니터·설정·트레이 종료·복구·절전·단일 실행. Electron API는 대역으로 검사 |
| 웹 공통 기능 회귀 검사 | 7개 통과. 이번 PC 작업은 웹 화면 코드를 변경하지 않음 |
| Windows 릴리스 | NSIS·무설치형 빌드 성공, 각각 약 98 MiB |
| 실제 Electron SDK | Windows에서 창 없이 초기화 성공, 종료 코드 0 |
| 패키지 확인 | 실제 SDK로 app.asar 모듈·512px 아이콘·복구 화면·지속 세션 읽기 성공 |
| 파일 무결성 | 두 EXE의 SHA-256 기록, 서버 전송 후 검증 |

직전 웹 작업에서 실제 운영 라이브러리·스트리밍과 PC·모바일 배치를 Chromium에서 확인했다.
이번 환경의 UI 도구는 Windows 네이티브 앱 조작을 지원하지 않아 **설치 UI, 실제 PC 앱 창에서의 로그인·재생·트레이 이동,
Windows 미디어 키와 장시간 재생은 직접 조작하여 확인하지 못했다.**
SDK 초기화와 대역 검사가 이 실제 UI 검사를 대신한다고 간주하지 않는다.
Windows 코드 서명은 적용하지 않았고 PC 런타임 자동 업데이트는 구성하지 않았다.

## 산출물과 다운로드

- `outputs/WavCloud-PC-0.1.0-x64-nsis.exe`
- `outputs/WavCloud-PC-0.1.0-x64-portable.exe`
- `outputs/WavCloud-PC-0.1.0-SHA256.txt`

운영 `/opt/cloudmusic/client/dist/downloads/`에 같은 파일을 추가했고 HTTPS 다운로드 응답 200과 파일 크기를 확인했다.
기존 APK와 웹 빌드·API·음원은 교체하지 않는다.
앱 ID `org.wavcloud.desktop`과 사용자 데이터 경로를 유지하면 새 설치본으로 업데이트할 수 있다.
사용 안내·다른 PC 빌드 절차·다운로드 링크는 [PC 앱 안내](../desktop-app/README.md)에 있다.
생성된 EXE·캐시·SDK·아이콘은 Git에서 제외한다.
