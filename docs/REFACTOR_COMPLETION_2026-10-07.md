# WavCloud 핵심 리팩토링 완료

Android 0.1.34 / versionCode 35. 개인용 앱이라는 사용 조건에 따라 인증 만료·갱신,
계정별 데이터 분리는 이번 완료 범위에서 제외했다. 기존 인증·계정 동작을 유지한다.

## 완료한 구조 변경

- 압축된 `runtime.js`를 제거하고 `LibraryView`, `PlayerView`, `MiniPlayerView`, `LoginView`,
  `AppController`, `AudioPlayer`를 각각 읽기 쉬운 파일로 옮겼다.
- `W`·`j`·`J`의 프로토타입 메서드 재정의를 클래스 메서드로 통합했다. 이전 동작이 필요한 부분은
  `renderLayout`, `renderTrackRows`, `renderFolderPlaylistDetail` 같은 클래스 내부 메서드로 호출한다.
- Android 재생은 `AndroidAudioPlayer`에서 구현한다. 실행 중 재생 객체의 메서드를 바꾸는 패치를 제거했다.
  기존 Media3 대기열 동기화·재연결·스펙트럼 계약은 유지했다.
- 재생 위치 갱신을 나머지 화면 갱신과 분리했다. 곡·재생·설정이 바뀔 때만 메타데이터·커버·컨트롤을 갱신한다.
  오프라인 조회는 곡 변경·화면 열기·저장·삭제 시 수행하며, 늦게 도착한 다른 곡의 결과는 반영하지 않는다.
- 업로드 코드를 `upload-dialog.js`로 분리하고 새 폴더 이름을 앱 내부 입력 창에서 받는다.
- 실행용 서버 코드를 바탕으로 `server/src`의 개발용 JavaScript를 재구성했다.
  원래 TypeScript 프로젝트는 발견되지 않았다. `build.js`가 문법을 검사하고 `dist`를 생성하며,
  `--check`가 소스와 빌드 결과의 일치를 검사한다. 수정 대상은 `src`다.
- 서버가 목록 스냅샷을 복원한 다음 API를 열고, 시작 스캔은 백그라운드로 진행한다.
  시작·HTTP 스캔은 같은 작업 관리자를 공유한다. 음원 크기·수정 시간과 외부 커버 지문을 검사해
  변경된 데이터만 다시 읽는다. 스캔 중 업로드도 최종 목록과 디스크 스냅샷에 보존한다.
- 스냅샷은 타입·경로·ID·소유 정보를 검사하고 임시 파일에서 원자적으로 교체한다.
  음악 경로가 없으면 새 빈 경로를 만들어 목록을 지우는 대신 기존 목록을 보존한다.
  첫 실행에 목록이 없으면 `/api/tracks`가 준비 상태 503을 반환하고 앱이 최대 60회, 2초 간격으로 확인한다.
- 개인용 Release APK를 기본 빌드로 추가했다. 디버깅 비활성화와 R8 최적화를 사용하며
  기존 설치 키로 서명한다. 별도 배포 키와 AAB 설정은 [빌드 안내](BUILD_VARIANTS.md)에 있다.

UI 검증은 로컬 테스트 API와 무음 WAV를 사용했다. 실제 휴대폰 설치, Media3 실제 음성,
잠금 화면·백그라운드·통신 단절 재생은 이번 실행에서 확인하지 않았다.
운영 PWA는 별도 배포물이며 그 원본 프로젝트는 이 저장소에 없다. UI 변경은 새 Android APK에 포함된다.

서버 코드는 운영에 반영했다. 운영 코드 해시 확인, 임시 환경 검사, 백업, 반영, 재시작과 API 검증,
실패 시 자동 복구 절차를 사용했다. 최종 백업은
`/opt/cloudmusic/backups/startup-refactor-20261007T074214Z`다.
`deploy-startup-refactor.sh`는 해당 변경의 기록이며 현재 운영 해시가 없는 상태로 그대로 재실행하지 않는다.

## 확인된 음원 데이터 문제와 복구

`/mnt/music/admin/음악 앨범/DJMAX Album/V LIBERTY 2/06 ESAI - Mad (feat. WaMi).wav`는 0바이트다.
메타데이터를 읽을 수 없어 스캔 대상 1,043개 중 정상 목록에는 1,042곡이 포함된다.
사용자가 제공한 Steam 원본 `DJMAX RESPECT V - V LIBERTY II Original Soundtrack/06 ESAI - Mad (feat. WaMi).wav`의
제목·앨범·전체 디코딩 상태를 확인하고 해당 서버 앨범에 등록했다.
기존 빈 WAV는 `/opt/cloudmusic/backups/song-repair-20261007T080203688Z`에 보존했다.
등록된 파일은 `06 ESAI - Mad (feat. WaMi).flac`이며 ID는 `1374678a5754`다.
48kHz·24비트·2채널, 길이 150.214초. 원본 WAV와 FLAC을 24비트 PCM으로 디코딩한 SHA-256이 동일하며,
새 곡의 Range 206 재생 응답과 등록 후 전체 스캔·재시작 복원을 확인했다.
